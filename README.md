# Premium 3D Fur Collectible Icon

Create or restyle living characters as premium 3D collectible icons with short, dense, carefully groomed fur while preserving their original identity and toy-like proportions.

![Premium short-fur collectible chipmunk](assets/chipmunk-short-fur-example.png)

## Use

```text
$premium-3d-fur-collectible-icon 이 캐릭터의 형태는 유지하고 짧고 부드러운 다람쥐 털 질감으로 바꿔줘
```

The skill separates character identity from fur references, keeps markings and facial geometry stable, and prevents realistic animal anatomy from overriding the source design.
